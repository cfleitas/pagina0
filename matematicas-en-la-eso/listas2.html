4. Obtener elementos de una lista, modificar elementos de una lista y añadir elementos a una lista

  1. Para obtener un elemento específico de una lista, puedes usar la función Element. Por ejemplo, para obtener el tercer elemento de la lista, puedes escribir:

    elTercero=Element(lista1, 3)

    la nueva variable es: elTercero contendrá el valor del tercer elemento de la lista y se actualizará cuando cambie la lista.

  2. Para modificar un elemento específico de una lista libre, como notas, puedes usar la función SetElement. Por ejemplo, para modificar el segundo elemento de la lista y asignarle el valor 15, puedes escribir:

    SetElement(notas, 2, 10)

  3. Para añadir un elemento a una lista existente, puedes usar la función Append. Por ejemplo, para añadir el número 11 a la lista existente (ojo, esto crea una lista nueva):

    Append(lista1, 11)

  4. Para añadir un elemento a una lista existente sin crear una nueva, puedes usar la función SetValue (siempre que la lista sea libre, no dependiente). Por ejemplo, para añadir el número 505 a la lista llamada lista2, si esta es de longitud 10, puedes hacer: 

    SetValue(lista1, 11, 505)

    Si no tienes ganas de contar los elementos, puedes usar la función Length para obtener la longitud de la lista y sumarle 1:

    SetValue(lista1, Length(lista1) + 1, 505)
